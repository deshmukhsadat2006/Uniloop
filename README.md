# UniLoop

> **Abstract** : UniLoop is a campus resource-sharing platform designed to connect students through the exchange and recovery of everyday essentials. It provides a centralized space where students can report missing belongings, discover found items, and lend or borrow resources such as books, calculators, and sports equipment. The platform incorporates intelligent text and image similarity techniques to suggest potential matches for lost belongings. With dedicated Student, Moderator, and Administrator roles, UniLoop supports secure interactions, ownership verification, and organized resource management. Developed using Java Servlets, JSP, JDBC, MySQL, Maven, and Apache Tomcat, UniLoop promotes a collaborative campus environment where useful resources stay in circulation and lost belongings have a better chance of finding their way home.
